# COCO BIBAN SHOP – Premium Footwear E-Commerce

Site e-commerce premium pour COCO BIBAN SHOP, boutique de chaussures hommes & femmes à Mokolo, Yaoundé, Cameroun.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Installation

```bash
cd coco-biban-shop
npm install
npm run dev
```

Ouvrez http://localhost:5173

## Fonctionnalités

- Identité visuelle luxury (noir, ivoire, champagne gold)
- Hero full-width avec animations
- Collections Hommes / Femmes
- 12 produits de démonstration (prix en FCFA)
- Filtrage par catégorie + recherche
- Bouton WhatsApp flottant + par produit (+237658962599)
- Sections À propos, Pourquoi nous, Contact
- Design 100% responsive
- Animations Framer Motion respectant prefers-reduced-motion
- Sticky header, menu mobile

## Notes

Les produits et prix sont des **démonstrations**. Remplacez les données dans `src/data/products.js` et configurez le numéro WhatsApp si nécessaire.

Images : Unsplash (URLs directes).

## Structure

```
src/
  App.jsx          # Application principale (tous les composants)
  data/products.js # Données produits démo
  index.css        # Tailwind + thème
  main.jsx
```
